# 九九消寒日记 (Lisp 99 Solution in yupian)

## 第一部 问第一至第十

### 其一 取列表之最末

「朷」也。入标准库矣。

### 其二 取列表之后数第二

勿用「朷」。弗利。乃知「朷」如何作也。

列表若为卜，则返卜。无中不能生有。
列表若只一项，亦返卜。
列表若有二，返其末。
若更多，则剥之。

### 其三 取某下标之元素

「柆」也。入标准库矣。然「柆」之义，与原问异焉：吾玉篇中，下标概以零为始。

### 其四 取列表之项数

暂作「十木」。待类型系统完好后，重载作「十」。

### 其五 逆转列表

为吾`口`之测试矣。

乃初次以`「卜」`作值。Typed Racket 之类型系统竟不似 Haskell, 
故 `'()` 非 `List`, 白马非马矣。
因改卜为 `(-> (Listof A))`, 将 `'()` 召来。
上古欲问吉凶，须燔甲骨作卜。今欲得 `'()`, 亦须用之，书`「卜」`以代。

今需编译器也。作一。

### 其六 回文列表

作列表之比较器焉。

### 其七 摊平列表

须作列表之合并器。各问无此事之问。

并作一`杸`以顺序投子。

### 其八 去相邻重项

作`橉`。

### 第九 以重项分组

与`橉` 似，唯初态及末态不同。解脱后需将暂存值补回。
